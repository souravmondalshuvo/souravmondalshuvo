### About

I'm a frontend developer who focuses on building practical, well-crafted tools. My main project right now is **Shohoj** — a CGPA calculator and academic toolkit built specifically for BRACU students, covering 758 courses across 16 departments.

I work primarily in vanilla HTML, CSS, and JavaScript, and I'm strengthening my foundations in Java and Data Structures & Algorithms.
